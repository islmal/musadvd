# STATUS — MusaDVD

> State as of **2026-11-19**. Architecture/context only; facts: `SYSTEM_STATE.txt`; build rules: `CLAUDE.md`; module docs: `handbook/`.

## 1. Mission & Out-of-Scope

Clean-room Rust DVD, Blu-ray, and AVCHD authoring suite (`musadvd` library + CLI, `musadvd-gui` Tauri 2 desktop app in German/English/Russian, plus **Burn Studio**). Arbitrary videos in → standards-compliant **DVD-Video** (`VIDEO_TS`, ConvertX-style or custom WYSIWYG menus) or **Blu-ray / AVCHD** (`BDMV` + `CERTIFICATE`) out, optionally burnt.

Principles: **clean room w.r.t. ConvertX** (only external `.ini` template files are read); `src/dvdvm.rs`, `src/dvd_mux.rs`, `src/ifo.rs`, and `src/spumux.rs` are **GPL ports/derivations of dvdauthor 0.7.2+**; `src/bd_mux.rs`/`src/bd_clip.rs` derive from **Apache-2.0 tsMuxer 2.7.0** (project license: `GPL-3.0-or-later`). Only `ffmpeg`/`ffprobe` remain external (`growisofs`/`xorriso` on Linux); everything else is native Rust.

**Out of scope / not implemented:** BD-J, Blu-ray pop-up menus, text outlines, template *outro* animation, HEVC/UHD output (HEVC is input only), custom BD size, multi-session, 8.3 camcorder AVCHD layout, MP2/TrueHD/E-AC-3 output, LPCM on DVD-Video, multi-angle, seamless branching, DVD-Audio, CSS, region coding, DVD-R DL layer break (drive default). On Linux, Burn Studio's MMC features (drive details, Discovery, Read, Verify, graphs) run over `SG_IO` but are not hardware-tested yet; tray eject/load/lock stays Windows-only, and the main app's DVD/BD burn still goes through `CliBurner` (`growisofs`/`xorriso`); macOS is unsupported.

## 2. System Architecture & Data Flow

- **DVD job (5 phases):** probe (`ffprobe`) → plan titles (merge groups) → **[1] menus** (`template.rs`/`menu.rs` or `layout.rs` → native `spumux.rs`) → bitrate from real menu size → **[2] videos** (parallel `ffmpeg` → MPEG-2 + AC-3 piped through native `spumux`) → **[3] authoring** (`author::author_dvd` → `dvdvm`/`dvd_mux`/`ifo` → `VIDEO_TS`) → **[4] ISO** (native UDF 1.02 + ISO 9660 bridge, layer break) → **[5] burn** (Windows IMAPI2 / Linux `growisofs`+`xorriso`).
- **Blu-ray / AVCHD:** `x264` or GPU H.264 (`nvenc`/`qsv`/`amf`, 1080i always `x264`) → MKV → native `bd_mux::mux_title` + `bd_clip` (CLPI/MPLS) → `hdmv.rs`/`bd_menu.rs` + IGS (`igs.rs`) + PGS (`pgs.rs`) → native UDF 2.50 (`udf250.rs`). Each title has its own size and frame rate (per-title overrides in the GUI's Video tab; menus follow title 1's rate, made valid for the menu size).
- **Blu-ray video copy (`BdVideoMode`: encode default / auto / strict, per-title override):** `encoder::bd_video_copy` checks codec/profile/level/pixel format/HDR/native BD format/trim/crop/average bitrate; at build time `bd_mux::scan_video` streams the video through the disc's buffer model (`h264::Vbv` at `limits().vbv_*`) and checks the IDR distance (≤ `BdRate::keyint`, 1 s). Copied titles are a fixed size in `bitrate_plan`; the encoded ones share the rest. Streams without Blu-ray timing get it from `bd_mux::TimingRepair` (rewritten SPS VUI timing + NAL HRD via `h264.rs`, buffering-period SEI at IDRs, picture-timing SEI on every picture, delays from the same buffer model), like tsMuxeR's `--insertSEI`.
- **Blu-ray audio copy (`BdAudioMode`: auto default / encode / strict):** `encoder::bd_audio_copy` is the single rule set: AC-3 (48 kHz, ≤ 6 ch, ≤ 640 kbit/s), DTS (48/96/192 kHz, ≤ 8 ch; DTS-HD only as its core via `dca_core`), integer PCM/FLAC ≤ 24 bit as lossless LPCM at the source rate. `auto` with an explicit `--audio ac3`/`lpcm` copies only tracks already in that format; `strict` fails before `bitrate_plan`. LPCM is sized at its wire rate (odd channel counts padded to even).
- **HDMV navigation (`bd_menu::plan`):** movie titles never `JumpObject`; a title end is `JumpTitle 0`, with the target menu object in `GPR8` that Top Menu dispatches and clears. Still menus use `still_mode` 2 (infinite) and still loop `SetButtonPage; PlayPL; Goto`. Settings-menu audio/subtitle buttons store per-title choices (`GPR16 + 2*(t-1)`); the title object applies them before `PlayPL` with register-form `SetStream`.
- **Menu elements:** text, image, video and `rect` (fill + optional border, drawn by the shared `layout::rect_image` in both renderers); `draftLayout` presets `swiss`/`cinema`/`midnight` restyle the draft without image assets (editor picker, one undo step).
- **Burn Studio (`burn_studio.rs` / `studio.rs`):** Windows IMAPI2 or direct MMC/SPTI (`mmcwrite.rs`), Discovery blank-media testing, Read, Verify, and `.ibg` graph telemetry (`graph.rs`). All MMC goes through the `ScsiTransport` trait (`spti.rs`): IMAPI `IDiscRecorder2Ex` / SPTI on Windows, `SgIoTransport` (`SG_IO` on `/dev/srN`, opened `O_NONBLOCK`, needs the `cdrom`/`optical` group) on Linux. On Linux every Burn Studio write (images, Discovery zeros, streamed builds) uses `mmcwrite::burn_direct_with`, because `CliBurner` has no `burn_source`; Read/Verify read the block device, sized by READ CAPACITY.
- **DVD video copy (`DvdVideoMode`: encode default / auto / strict):** `encoder::dvd_video_copy` copies compliant MPEG-2 (no trim/crop/scale/deinterlace/picture filters); copies are fixed-size in `bitrate_plan` (`copy_bytes`), `strict` fails before menus.
- **Picture filters & quality test:** `denoise`/`eq` live in `VideoProcessing` and `source_chain`, so preview and encode share one filtergraph; `test_title_quality` encodes a 10 s sample and reports PSNR. Scene chapters come from `probe::detect_scene_chapters`; the editor's Test Remote mode uses `layout::menu_button_navigation` (= `author::compute_navigation`).
- **Two-pass MPEG-2:** pass 1 is a fast statistics-only run (same GOP/rate control); pass 2 uses `-mbd rd`, plus `-trellis 1 -intra_vlc 1` unless `--fast`.
- **Live player (`preview.rs`):** Loopback HTTP fMP4 proxy from `ffmpeg` (480p ultrafast, shared `source_chain` with deinterlace → HDR tonemap → crop → picture filters).
- **i18n & config:** Single locale JSONs (`frontend/src/locales/*.json`, `en.json` master and default language) shared by GUI and engine. Settings at `%APPDATA%\musadvd\settings.json` (Windows) or `$XDG_CONFIG_HOME/musadvd/settings.json` (Linux); work dir `<project>.musadvd-work`.
- **GPU decoding:** `hw_decode: true` by default; `probe_hwaccel` tests vendor-preferred then fallback platform decoders (`d3d11va`/`cuda`/`qsv` on Windows; `cuda`/`vaapi`/`qsv` on Linux) via 2 s `ffmpeg` probe.

**Quirks (easy to get wrong):**
- `ffmpeg` `-ss` + stream-copied audio fails to cut start → trimmed titles always re-encode audio.
- `dvd` muxer LPCM causes PTS discontinuities → `lpcm` mode writes AC-3 on DVD.
- `growisofs` reports `%` on `stdout` (not `stderr`) and may leave `/dev/sr0` settling (`ENOMEDIUM` = 123) right after closing session → `unix.rs` drains both pipes and retries `open_for_verify`.
- Most web rips cannot be copied: x264's default GOP (`keyint` 250) breaks the 1 s IDR rule, and `ultrafast` x264 is Constrained Baseline even with `-profile high`.
- Interlaced (field-coded) H.264 is copied only when it already carries Blu-ray timing; its buffer and GOP are not scanned.
- VLC/libbluray accepts HDMV and playlist errors (timed still with 0 s, `JumpObject` in a movie title, `SetStream` for a stream the current playlist lacks); the PS4 (FW 10.50) does not → test BD navigation on the PS4 (`handbook/testing.md`).
- Register-form `SetStream`: flags stay immediate, the 12-bit number fields name the GPRs that hold the stream numbers – the operand is not one register's value.
- `tauri.windows.conf.json` holds `../bin/*.exe` and `nsis` targets; `tauri.linux.conf.json` holds `deb`/`appimage` targets so Linux builds do not fail on missing `.exe` globs.

## 5. Dead Ends & Anti-Patterns
- PS4 still menu closes after ~1 s: ✗ IG/menu clip too short → ✓ MPLS `still_mode` 1 (timed) with `still_time` 0; infinite is 2.
- PS4 crashes at every title end: ✗ playlist end / overlay state → ✓ `JumpObject` from a movie title into an interactive menu object; leave with `JumpTitle 0`.
- Settings-menu audio choice ignored (PS4, then VLC): ✗ wrong stream index → ✓ the menu playlist lacks the title's streams; a register-form `SetStream` takes GPR numbers in its fields, not a whole operand from one register.
- Old e-mail in rewritten history: ✗ mailmap covers it → ✓ needs `git filter-repo --replace-text`.
- GitHub `refs/pull/*/head` survive mirror push: ✗ `push --force --mirror` removes them → ✓ PR refs are read-only; only Support or a new repo removes them.
- Linux burn progress stuck at 15%: ✗ `growisofs` writes `%` to `stderr` → ✓ `growisofs` writes `%` to `stdout`; drain both `stdout` and `stderr`.
- Tauri Linux build fails on `../bin/*.exe`: ✗ shared `tauri.conf.json` resources → ✓ move `.exe` glob to `tauri.windows.conf.json`.
- Linux AppImage freezes when the trim tab opens: ✗ ffmpeg preview child / UI-thread kill → ✓ missing GStreamer plugins in the bundled web view (`appsink`/`autoaudiosink` not found); bundle the media framework. Still silent in 0.1.3 (preview is H.264+AAC fMP4, WebVTT warning): `bundleMediaFramework` only copies plugins installed on the CI runner → install `gstreamer1.0-libav`/`-plugins-good`/`-plugins-bad` there (unverified until the next AppImage).
- Copy test reads odd HRD values (15/5-bit delays, 4-byte picture timing): ✗ wrong SPS writer → ✓ a stale `cx_bluray_vcopy_*` folder of an earlier run (re-encoded by x264) was inspected; pick test folders by time (`ls -dt`) and clear them.
- Locale keys instead of text on Linux: ✗ broken locale JSON → ✓ package layout puts resources in `<prefix>/lib/<productName>`, not next to the exe; add the package paths to `i18n::locales_dirs`.
