# STATUS — MusaDVD

> State as of **2026-11-25** (1.5.1). Architecture/context only; facts: `SYSTEM_STATE.txt`; build rules: `CLAUDE.md`; module docs: `handbook/`.

## 1. Mission & Out-of-Scope

Clean-room Rust DVD, Blu-ray, and AVCHD authoring suite (`musadvd` library + CLI, `musadvd-gui` Tauri 2 desktop app in German/English/Russian, plus **Burn Studio**). Arbitrary videos in → standards-compliant **DVD-Video** (`VIDEO_TS`, ConvertX-style or custom WYSIWYG menus), **Blu-ray** (`BDMV` + `CERTIFICATE`) or **AVCHD** on DVD media (`BDMV` in AVCHD form) out, optionally burnt.

Principles: **clean room w.r.t. ConvertX** (only external `.ini` template files are read); `src/dvdvm.rs`, `src/dvd_mux.rs`, `src/ifo.rs`, and `src/spumux.rs` are **GPL ports/derivations of dvdauthor 0.7.2+**; `src/bd_mux.rs`/`src/bd_clip.rs` derive from **Apache-2.0 tsMuxer 2.7.0** (project license: `GPL-3.0-or-later`). Only `ffmpeg`/`ffprobe` remain external (`growisofs`/`xorriso` only as Linux burn fallback); everything else is native Rust.

**Out of scope / not implemented:** BD-J, Blu-ray pop-up menus, text outlines, template *outro* animation, HEVC/UHD output (HEVC is input only), custom BD size, multi-session, 8.3 camcorder AVCHD layout, MP2/TrueHD/E-AC-3 output, LPCM on DVD-Video, multi-angle, seamless branching, DVD-Audio, CSS, region coding, DVD-R DL layer break (drive default). Linux Burn Studio's MMC features (drive details, Discovery, Read, Verify, graphs) run over `SG_IO` and were verified on hardware (maintainer report); tray eject/load/lock stays Windows-only; the main app's burn on Linux is native MMC over `SG_IO` (`unix.rs`, tools only as fallback, and for erasing a used DVD-RW: no native BLANK yet); macOS is unsupported.

## 2. System Architecture & Data Flow

- **DVD job (5 phases):** probe (`ffprobe`) → plan titles (merge groups) → **[1] menus** (`template.rs`/`menu.rs` or `layout.rs` → native `spumux.rs`) → bitrate from real menu size → **[2] videos** (parallel `ffmpeg` → MPEG-2 + AC-3 piped through native `spumux`) → **[3] authoring** (`author::author_dvd` → `dvdvm`/`dvd_mux`/`ifo` → `VIDEO_TS`) → **[4] ISO** (native UDF 1.02 + ISO 9660 bridge, layer break) → **[5] burn** (Windows IMAPI2 or direct MMC / Linux native MMC over `SG_IO`, tools as fallback).
- **Blu-ray / AVCHD:** `x264` or GPU H.264 (`nvenc`/`qsv`/`amf`, 1080i always `x264`) → MKV → native `bd_mux::mux_title` + `bd_clip` (CLPI/MPLS) → `hdmv.rs`/`bd_menu.rs` + IGS (`igs.rs`) + PGS (`pgs.rs`) → native UDF 2.50 (`udf250.rs`). Each title has its own size and frame rate (per-title overrides in the GUI's Video tab; menus follow title 1's rate, made valid for the menu size).
- **AVCHD form (`bd::avchd_versions`, `hdmv::avchd_index`):** like tsMuxeR's AVCHD: `BDMV` at the root with long names, version `0100` in index/MovieObject/MPLS/CLPI (BACKUP too), tsMuxeR's 406-byte `IDEX` ExtensionData appended to `index.bdmv`, `AUXDATA` kept, BD-J/META folders and `CERTIFICATE` dropped. Verified on PS3 and PS4. BD-25/50 stay `0200` + `CERTIFICATE`.
- **Size planning (`dvd::bitrate_plan_at`):** floor by frame size (`min_video_kbps`: DVD 1000/600/400 for Full D1/Half D1/SIF, BD 2500 1080p / 1500 720p, AVCHD ≤ 2000); Blu-ray overhead = 8 % of every muxed stream (`BD_STREAM_OVERHEAD_RATIO`, measured 7.7 %), PGS 40 kbit/s per track (measured ~32), DVD 10; `hw_reserve_mb` keeps 0.5 % free with NVENC/QSV/AMF, in the build and `calculate_project` alike. Quality badges: DVD as Full-D1-equivalent bits per pixel, BD H.264 by bits per pixel (`h264_quality`).
- **Titles & tracks:** the 99-title limit counts merge groups (`dvd::check_title_count`); a merged DVD title > 99 chapters blocks Convert ("Split automatically", `order.ts autoSplitPoints`). List order is disc order; embedded and external subtitles are one list (`StreamSelection::subtitle_order` → per-title `sub_order` permutation for labels, menu sources, IFO, spumux ids and BD sup files; GUI `subKinds`).
- **Project settings:** disc options (`PROJECT_SETTING_KEYS`) are edited in the main window's Project settings tab, applied on every change and saved in the `.musadvd` `settings` object (`withProjectSettings` on load); the General dialog keeps app-level options.
- **Blu-ray video copy (`BdVideoMode`: encode default / auto / strict, per-title override):** `encoder::bd_video_copy` checks codec/profile/level/pixel format/HDR/native BD format/trim/crop/average bitrate; at build time `bd_mux::scan_video` streams the video through the disc's buffer model (`h264::Vbv` at `limits().vbv_*`) and checks the IDR distance (≤ `BdRate::keyint`, 1 s). Copied titles are a fixed size in `bitrate_plan`; the encoded ones share the rest. Streams without Blu-ray timing get it from `bd_mux::TimingRepair` (rewritten SPS VUI timing + NAL HRD via `h264.rs`, buffering-period SEI at IDRs, picture-timing SEI on every picture, delays from the same buffer model), like tsMuxeR's `--insertSEI`.
- **Blu-ray audio copy (`BdAudioMode`: auto default / encode / strict):** `encoder::bd_audio_copy` is the single rule set: AC-3 (48 kHz, ≤ 6 ch, ≤ 640 kbit/s), DTS (48/96/192 kHz, ≤ 8 ch; DTS-HD only as its core via `dca_core`), integer PCM/FLAC ≤ 24 bit as lossless LPCM at the source rate. `auto` with an explicit `--audio ac3`/`lpcm` copies only tracks already in that format; `strict` fails before `bitrate_plan`. LPCM is sized at its wire rate (odd channel counts padded to even).
- **HDMV navigation (`bd_menu::plan`):** movie titles never `JumpObject`; a title end is `JumpTitle 0`, with the target menu object in `GPR8` that Top Menu dispatches and clears. Still menus use `still_mode` 2 (infinite) and still loop `SetButtonPage; PlayPL; Goto`. Settings-menu audio/subtitle buttons store per-title choices (`GPR16 + 2*(t-1)`); the title object applies them before `PlayPL` with register-form `SetStream`.
- **Menu elements:** text, image (optional normalized `crop`, applied before fit), video, `icon` (`assets/icons/*.svg` via `resvg`, alpha = highlight shape; the same SVGs feed the editor through Vite `?raw`) and `rect` (fill + optional border, drawn by the shared `layout::rect_image` in both renderers); `draftLayout` presets `swiss`/`cinema`/`midnight` restyle the draft without image assets (editor picker, one undo step). Draft themes: `landing` (retail single screen, default) and `classic` (6-thumbnail grid); `settingsMode` `global` (one shared audio/subtitle menu, default for multi-title) or `perTitle`.
- **Global stream choice:** `setGlobalAudio`/`setGlobalSubtitle` buttons store the choice (DVD `g11` audio 1-based / `g12` SPRM2 value, 1 = off; BD `GPR4000/4001`), applied on title entry only when the title has the track; a title's own settings button clears it (last choice wins). DVD: `g13`-`g15` are VM temporaries, so `g12` is the highest free GPRM; a `customVm` writing `g11`/`g12` breaks it.
- **Text look & D-pad:** text elements may carry box fill (opacity, `rx`/`ry` corners, padding), shadow (colour, opacity, X/Y, blur) and outline, painted by one `layout::draw_text_element` for DVD and BD (fill → shadow → outline → text; highlight mask = glyph coverage only; the default 2-unit shadow now scales like explicit offsets, so output only changes where canvas and frame heights differ). Buttons may override D-pad targets (`nav`, applied by `apply_nav_overrides` after `compute_navigation`, also for Test Remote) and `autoExecute` (DVD spumux `autoaction` → PCI 0x40, BD per-button `auto_action_flag`); menus never start focused on an auto button (DVD `s8 = Nk` in `pre`, BD reorders so button id 1 is not auto).
- **After playback, menu play modes, indicators:** per-title `afterPlayback` (last file of a merged entry) replaces the disc-wide end rule in the DVD VMGM dispatcher / BD title end; a running Play All keeps advancing except for `loop`. Menu `playMode`: `once` = DVD cell still 255 without loop post / BD `still_mode` 2; `onceActivate` = DVD still `timeoutSecs` + start-button command as post / BD clip of duration+timeout, then the start button's commands inline after `PlayPL` (no timed still – PS4). `indicatorFor` elements are not drawn; their shape joins the target button's highlight/select masks and the button rectangle becomes the union (validated against overlap). Editor: batch apply (`applyStyleBatch`), smart guides/grid (`snap.ts`), stretch icons generated per box size (`icon_svg_sized` / `iconSvg(…, w, h)`).
- **Burn Studio (`burn_studio.rs` / `studio.rs`):** Windows IMAPI2 or direct MMC/SPTI (`mmcwrite.rs`), Discovery blank-media testing, Read, Verify, and `.ibg` graph telemetry (`graph.rs`). All MMC goes through the `ScsiTransport` trait (`spti.rs`): IMAPI `IDiscRecorder2Ex` / SPTI on Windows, `SgIoTransport` (`SG_IO` on `/dev/srN`, opened `O_NONBLOCK`, needs the `cdrom`/`optical` group) on Linux. On Linux every Burn Studio write (images, Discovery zeros, streamed builds) uses `mmcwrite::burn_direct_with`, because `CliBurner` has no `burn_source`; Read/Verify read the block device, sized by READ CAPACITY.
- **Burn Studio labels:** the build view has two fields: the ISO 9660/Joliet label (main-burner rules, A–Z 0–9 _, 32) and a free-text UDF label (Latin-1, 30 = one 32-byte CS0 dstring) written to the UDF 1.02 bridge or UDF 2.50 descriptors (`ImagePlan`/`BdImagePlan::udf_label`, empty = the ISO label, so the main burner's images are unchanged). The ISO descriptors read `plan.label`, every UDF descriptor `plan.udf_label`.
- **Native erase:** `mmcwrite::blank_disc` sends MMC BLANK (0xA1, IMMED, minimal 0x01 / full 0x00) exactly once and polls TEST UNIT READY, reading the sense-key-specific progress of 2/04/07; GET CONFIGURATION guards the profile (CD-RW/DVD-RW only; DVD+RW/BD-RE need none, write-once is refused). A running BLANK cannot be cancelled. Used by Burn Studio (Erase mode), `musadvd erase` and the direct MMC write path when `erase` is set (sequential DVD-RW); Linux uses it on every SG_IO burn, `xorriso -blank` only when SG_IO cannot open the drive; the Windows IMAPI path keeps IMAPI erase.
- **DVD video copy (`DvdVideoMode`: encode default / auto / strict):** `encoder::dvd_video_copy` copies compliant MPEG-2 (no trim/crop/scale/deinterlace/picture filters); copies are fixed-size in `bitrate_plan` (`copy_bytes`), `strict` fails before menus. In the GUI it is the `dvd_video` setting (main-window row, a project setting); older `.musadvd` files carry it as `dvdVideo`, re-applied on load like `tvStandard`. `probe_file` returns the stream verdict per TV standard (`dvdCopyKbps`/`dvdCopyIssue`); `main.ts::dvdCopy` adds resolution, aspect policy, trim, crop, filter, deinterlace and scale checks for badges, size estimate, strict gate and pre-flight.
- **Picture filters & quality test:** `denoise`/`eq` live in `VideoProcessing` and `source_chain`, so preview and encode share one filtergraph; `test_title_quality` encodes a 10 s sample and reports PSNR. Scene chapters come from `probe::detect_scene_chapters`; the editor's Test Remote mode uses `layout::menu_button_navigation` (= `author::compute_navigation`).
- **Two-pass MPEG-2:** pass 1 is a fast statistics-only run (same GOP/rate control); pass 2 uses `-mbd rd`, plus `-trellis 1 -intra_vlc 1` unless `--fast`.
- **Live player (`preview.rs`):** Loopback HTTP fMP4 proxy from `ffmpeg` (480p ultrafast, shared `source_chain` with deinterlace → HDR tonemap → crop → picture filters).
- **i18n & config:** Single locale JSONs (`frontend/src/locales/*.json`, `en.json` master and default language) shared by GUI and engine. Settings at `%APPDATA%\musadvd\settings.json` (Windows) or `$XDG_CONFIG_HOME/musadvd/settings.json` (Linux); work dir `<project>.musadvd-work`.
- **GPU decoding:** `hw_decode: true` by default; `probe_hwaccel` tests vendor-preferred then fallback platform decoders (`d3d11va`/`cuda`/`qsv` on Windows; `cuda`/`vaapi`/`qsv` on Linux) via 2 s `ffmpeg` probe.

**Quirks (easy to get wrong):**
- `ffmpeg` `-ss` + stream-copied audio fails to cut start → trimmed titles always re-encode audio.
- `dvd` muxer LPCM causes PTS discontinuities → `lpcm` mode writes AC-3 on DVD.
- `growisofs` reports `%` on `stdout` (not `stderr`) and may leave `/dev/sr0` settling (`ENOMEDIUM` = 123) right after closing session → `unix.rs` drains both pipes and retries `open_for_verify`.
- Most web rips cannot be copied: x264's default GOP (`keyint` 250) breaks the 1 s IDR rule, and `ultrafast` x264 is Constrained Baseline even with `-profile high`.
- Interlaced (field-coded) H.264 is copied only when it already carries Blu-ray timing; its buffer and GOP are not scanned.
- VLC/libbluray accepts HDMV and playlist errors (timed still with 0 s, `JumpObject` in a movie title, `SetStream` for a stream the current playlist lacks); the PS4 (FW 10.50) does not → test BD navigation on the PS4 (`handbook/testing.md`).
- Register-form `SetStream`: flags stay immediate, the 12-bit number fields name the GPRs that hold the stream numbers – the operand is not one register's value.
- NVENC lands ~3 % under its target bitrate, which hid a too-small BD overhead model; re-measure the model from `--keep-work` builds (`handbook/testing.md`), never from the final size alone.
- ffmpeg's `bluray:` protocol skips playlists under 3 minutes ("0 usable playlists"): libbluray checks need long clips.
- The nightly release's asset names repeat per version and `tauri-action` never overwrites: `release.yml` clears the nightly assets first.
- `tauri.windows.conf.json` holds `../bin/*.exe` and `nsis` targets; `tauri.linux.conf.json` holds `deb`/`appimage` targets so Linux builds do not fail on missing `.exe` globs.

## 5. Dead Ends & Anti-Patterns
- PS3 shows an AVCHD DVD as "Data Disc": ✗ `AVCHD/BDMV` with 8.3 names (that is the FAT camcorder-card layout) → ✓ root `BDMV`, long names, `0100` versions + tsMuxeR's IDEX block in `index.bdmv`.
- AVCHD-5 builds 3-22 MB over 4300: ✗ NVENC overshooting its bitrate (it lands ~3 % under) → ✓ BD overhead model too small (BDAV 7.7 % of the streams vs 6 % of the disc; PGS 32 vs 10 kbit/s).
- libbluray "0 usable playlists" on a fresh AVCHD build: ✗ `0100`/IDEX/missing CERTIFICATE → ✓ ffmpeg's `bluray:` protocol skips playlists under 3 min.
- PS4 still menu closes after ~1 s: ✗ IG/menu clip too short → ✓ MPLS `still_mode` 1 (timed) with `still_time` 0; infinite is 2.
- PS4 crashes at every title end: ✗ playlist end / overlay state → ✓ `JumpObject` from a movie title into an interactive menu object; leave with `JumpTitle 0`.
- Settings-menu audio choice ignored (PS4, then VLC): ✗ wrong stream index → ✓ the menu playlist lacks the title's streams; a register-form `SetStream` takes GPR numbers in its fields, not a whole operand from one register.
